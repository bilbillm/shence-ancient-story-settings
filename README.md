# 沈策古风剧情设定完整版

这是一份以沈策为中心的中文古风人物设定集，正文题为《沈策 · 个人设定全集》。沈策字无咎，号寒江钓客，江湖人称“断眉沈”。他幼年从沈家渡惨案中幸存，此后流落各地，做过小吏、行走江湖，也曾守过孤城。档案沿“永嘉”纪年记录他的经历，以及他舍弃本名后的行迹。

## 内容结构

按卷首目录，全书分十卷、附二卷。总纲和本传勾勒人物经历，逐日编年和后编记录其行迹，其余各卷收录案牍、人际关系、书简、武学、器物和异闻，卷末附有遗文及后人评。正文用「记」「附」「按」等标记区分本人自述、旁人转述与考据，同一事件有时并录多种说法。
